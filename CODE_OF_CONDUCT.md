# Code of conduct

## Our pledge

We want participation in this project to be free of harassment for everyone,
regardless of experience, background, identity or language.

## Expected behaviour

- Be precise about technical claims and generous about people.
- Critique code and documents, not contributors.
- Assume a question is asked in good faith; answer it at the level it was asked.
- Respect that the maintainers make the final call on scope.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, publishing private
information, and sustained disruption of discussions are not tolerated.

## Enforcement

Report concerns to the maintainers through the repository profile or a private
security advisory if the report is sensitive. Maintainers may edit or remove
comments, close threads, or block accounts. Decisions are recorded privately and
explained to the people involved.
