每次研究调用惰性缓存各日期有限的、预处理后因子排序。每个 horizon 按自己的
有限标签过滤该顺序，再重新计算 qcut 边界和 midrank；不复用其他 horizon 的
边界或秩。输出仍按 panel 顺序，qcut 异常、max_loss、诊断顺序和 Pearson
算术不变。缓存约增加 8N 字节，局部映射 scratch 只随最大日期截面增长。

独立静态审阅无阻塞；Root Release 构建、55 项相关测试及 3 个实际 Python
oracle 场景通过。新增测试覆盖不同 horizon 有效样本以及单个/两个带符号零。
