# P121 R2：大截面的稳定浮点基数排序

2026-10-25，现有 dev，父提交 `b7891ae86441a74f969457d6d7fa1d552f02364e`。
本记录与五个源代码/测试路径同次提交，提交身份可由 Git 历史定位。

大于等于 1024 项时，用稳定 LSD 基数排序排列索引；小截面保留比较排序。
IEEE binary64 的整数键保持有限值与无穷的数值顺序，把正负零归为同一个键，
调用方继续按原规则过滤 NaN。一次扫描统计八个字节的直方图，跳过只有一个桶的
轮次，复用独立 scratch，并在实际轮数为奇数时复制回原索引数组。
不改变秩、qcut、相关系数的浮点运算顺序或公开结果拥有权。

独立静态审查无阻塞。Root Release 构建、72 项相关测试和 3 个实际 Python
oracle 场景通过。测试覆盖阈值两侧、随机非 NaN 位模式、极值/无穷/次正规数、
正负零/ties、单字节差异和不同长度间的 scratch 复用，精确比较稳定参考顺序。

## 热点与计划修订依据

优化前的全量 Python/C++ 五对开发测量全部结果一致，但 wall 中位数
70.852317/5.062757 s，C++ 噪声 43.18%，不能声称稳定 13.99× 或稳定退化。
较慢样本在加载/导出阶段出现额外等待；没有证据将其唯一归因于磁盘或其他进程。
以该 Python 中位数估算，30× 需要 C++ 不超过 2.361744 s，这只是下一轮预算。

WPR CPU 采样启动返回 `0xc5585011`（无法启用系统性能 profiling policy），
前后状态均为未录制，没有生成采样证据。改用冻结源码的粗阶段 steady-clock
计时，单次完整 13 文件字节通过：进程 wall 3.234319 s；因子内部 0.389708 s，
其中秩排序 0.210793 s、滚动相关与物化 0.173222 s。研究内部 1.187775 s，
其中选择/预处理 0.188232 s、标签构造 0.216900 s、结果物化 0.253822 s、
horizon 处理 0.487465 s、稳定性 0.040381 s；horizon 内部 IC 等计时是其子项，
不重复相加。此结果是单次粗阶段诊断，不能冒充 CPU 采样或性能验收。

为预留测量空间，对四个已完成的历史输出目录做 NTFS 原位压缩，逐文件核对
全部路径/大小/SHA-256。没有删除文件、改动逻辑字节、输入数据或未来输出目录。
压缩不与计时并发，也不被当作噪声成因或优化收益证明。
