**Goal:** Add `twr`: the geometric compound of NaN-cleaned per-period returns.

**Baseline:** `dev` after the Iteration 1 close-out (oracle pin `4b8f31b`).
Python source: `fincore/performance/returns.py::twr` (lines 32–39).

**Files:** `include/fincore/performance/returns.hpp` (new),

`tests/unit/performance_returns_test.cpp` (new), `tests/CMakeLists.txt`.

## Native API

```cpp
double twr(const dataframe& returns, std::string_view column = returns_column);
```

## Contract

```text
NUL selector check -> require_double_column
product = 1; for each non-NaN value: product *= 1 + value
return product - 1
```

No cashflow-event subdivision in this phase (that is Phase 56). Empty and
all-NaN inputs return `0.0` because NumPy's empty product is one. Total loss
(`-1`) returns `-1`; returns below `-1` keep the negative product; signed
infinities propagate.
