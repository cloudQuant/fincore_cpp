# Phase 54 Native MWR Plan

**Goal:** Add `mwr`: internal rate of return for equally spaced or
fixed-interval cashflows, reusing the Phase 55 solver.

**Baseline:** `dev` after Phase 55 (oracle pin `4b8f31b`). Python source:
`fincore/performance/returns.py::mwr` (lines 244–268).

**Files:** `include/fincore/performance/returns.hpp`,
`src/performance/returns.cpp`, `tests/unit/performance_returns_test.cpp`.

## Native API

```cpp
double mwr(const dataframe& cashflows,
           std::optional<double> period = std::nullopt,
           std::string_view amount_column = "cashflow");
```

Cashflows are positional (the frame index is ignored, matching the Python
array contract); `period` is the year-length of each interval and defaults to
one.

## Contract

```text
NUL check -> require_double_column
fewer than two cashflows -> input_error
non-finite amount -> input_error
period present and not positive/finite -> input_error
times = position * interval (or position when absent)
drop zero cashflows but retain their original times
shared IRR contract: one sign transition, scaled log-gross NPV, bracket
opposition, bisection; non-conventional -> NaN
```

## Tests

Goldens for two/three flows, half-period interval, zero-coefficient retention
of positional time (`0.048808848170151624`), and loss; non-conventional,
all-negative, single-flow, non-finite, and invalid-period classes; selector
and ownership.
