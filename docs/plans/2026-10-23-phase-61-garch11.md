# Phase 61 Native GARCH(1,1) Fit Plan

**Goal:** Add a GARCH(1,1) maximum-likelihood fit with zero or constant mean,
conditional-variance recursion, standardized residuals, log-likelihood, and
forecasting, following the Phase 60 solver decision.

**Baseline:** `dev` after Phase 60 (oracle pin `4b8f31b`). Python source:
`fincore/risk/garch.py` (`GARCH`, `GARCHResult`, lines 40–292).

**Files:** `include/fincore/risk/garch.hpp` (new), `src/risk/garch.cpp`

## Native API

```cpp
struct garch11_parameters { double mu, omega, alpha, beta; };
struct garch11_result {
    garch11_parameters params;
    std::vector<double> conditional_variances, residuals;
    double log_likelihood;
    bool converged;
};
double garch11_log_likelihood(std::span<const double> eps,
                              double omega, double alpha, double beta);
garch11_result fit_garch11(const dataframe&, bool constant_mean = false,
                           column = returns_column);

```

## Contract

- NaN-only cleaning; fewer than 11 clean observations → `input_error`
  (`Insufficient data for GARCH estimation`).
- Initialization: `mu = mean` (constant mean) or 0; `omega = 0.1*var`;
  `alpha = 0.1`; `beta = 0.85`.
- Bounds: `omega >= 1e-6`, `alpha, beta in [1e-6, 1]`, enforced through
  positive/sigmoid transforms and Nelder-Mead in unconstrained space.
- Conditional variance: `sigma2[0] = population var(eps)`, then
  `omega + alpha*eps[t-1]^2 + beta*sigma2[t-1]`.
- Gaussian log-likelihood over positions 1..T-1 (burn-in one observation).
- `converged` requires optimizer convergence, finite parameters, positive
  omega, non-negative alpha/beta, and `alpha + beta < 1`.
- Forecast: one-step `omega + alpha*eps_last^2 + beta*var_last`, then
  persistence `alpha + beta`.
