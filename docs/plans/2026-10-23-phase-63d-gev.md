## Native API

```cpp
struct gev_parameters { double xi; double mu; double sigma; std::size_t n_blocks; };
gev_parameters gev_fit(data, block_size, tail, column);
// evt_var / evt_cvar / extreme_risk accept evt_model::gev;
// extreme_risk_result gains optional location, scale, n_blocks.
```

## Contract

- Default block size `int(sqrt(n))`; `n_blocks = n / block_size`; lower tail
  uses negated block minima, upper tail block maxima.
- Reproduce `scipy.stats.genextreme.fit`: shape start `c = +0.5` for negative
  adjusted skew else `-0.5`; moment-based loc/scale (including the
  infinite-variance `(mean, 1)` case); support fallback; `fmin`
  Nelder-Mead with `xtol=ftol=1e-4`, `maxiter=maxfun=600`; penalized
  negative loglikelihood that drops unsupported observations and adds
  `log(max double) * 100` per drop. Return `xi = -c`.
- GEV VaR uses `t = -log1p(-alpha)`; GEV CVaR uses the Gumbel E1 form or the
  lower incomplete gamma for `xi < 1`, rejecting `xi >= 1`.
- `extreme_risk` GEV reports VaR, CVaR, tail index, location and scale;
  threshold/exceedance fields are not applicable.

## Tests
